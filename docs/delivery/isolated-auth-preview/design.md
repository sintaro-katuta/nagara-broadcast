# 設計

専用の `nagara-auth-staging` Worker は期限付きの共有トークンを URL fragment から受け取り、本人のブラウザに HttpOnly Cookie を発行する。未認証リクエストや不正なオリジン、期限切れ、未設定時は閉じる。すべての静的ファイルも Worker を経由し、検索インデックスとキャッシュを抑止する。本番ホストでは動かない。

設定生成は本番と異なる D1 ID、固定したテスト用 workers.dev ホスト、24時間以内の期限を要求する。Worker 名も本番とは別で、R2 をバインドしない。送信専用 Resend キーと3種類の認証鍵、入口トークンはテスト用を別途 secrets として設定する。テスト Worker の Cron は無効であり、復旧完了通知の定期送信はこの環境だけでは検証できない。

共有リンクを知る人はテスト環境にアクセスできる。Cloudflare Access の代替としての保証はなく、認証レビュー前にテスト目的でのみ使う。テストの D1 に実アドレスが記録され得るため、検証終了時は削除する。
