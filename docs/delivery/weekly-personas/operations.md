# 運用

人物像の修正は `docs/weekly-personas.md` を編集し、`npm test` を実行する。次に新規作成される台本から参照される。既に `script.json` または `ready.json` がある日には自動再生成されない。設定と異なる発話は該当回の生成台本、人物設定、`data/weekly/logs/` を確認する。

新しいコードと文書を制作するMac上に配置する。認証・音声エンジンや公開に関する運用は [既存手順](../weekly-cloud/operations.md) に従う。データ移行は不要。元に戻す場合は、この変更に含まれる人物設定、読み、プロンプト参照を一緒に以前の版へ戻す。公開済み音声は変更されない。
