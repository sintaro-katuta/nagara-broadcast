# 設計

Cloudflare WorkerのCron Triggerを毎時実行する。`AUTH_CLEANUP_ENABLED` が文字列 `true` の場合のみD1を更新し、実行予定時刻以前に期限切れとなった一時データを、8種類のテーブルごとに最大200件削除する。D1のバッチでまとめて実行し、失敗時は全体をロールバックする。件数のみをログに記録し、メールアドレス、トークン、ユーザーIDは記録しない。

セッション・トークン等の有効判定は `expires_at > 現在時刻` のため、同値の行も削除対象とする。期限の基準は秒、Cronの予定時刻はミリ秒で受け取り変換する。実行が遅れた場合も未来の期限を削除しない。課金や負荷を抑えるため一度で全件削除しない。

アカウント、パスキー、メールアドレス、履歴、お気に入り、再生位置の順序管理カーソルは削除しない。順序管理カーソルを期限で削除すると、遅延した古い更新が再び受理される可能性があるため、別の保持設計が必要。
