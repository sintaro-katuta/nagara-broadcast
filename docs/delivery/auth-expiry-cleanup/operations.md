# 運用

マージ後のデプロイでCronは毎時呼び出されるが、`AUTH_CLEANUP_ENABLED` が `true` でなければD1にはアクセスしない。認証の公開を許可する設定ではない。

有効化前にD1のバックアップ・復元手順を確認し、認証用の全マイグレーション `0001`〜`0014` を適用済みにする。ステージングのD1で期限切れと有効なデータを用意して、定期実行と失敗時のログを確認する。実行停止は `AUTH_CLEANUP_ENABLED` を `false` にして再デプロイする。

Workerのログにはテーブル別の削除件数のみを出力する。毎回200件のテーブルが続く場合は期限切れの蓄積が処理能力を上回っている可能性があるので、残件数・書き込み量を確認して実行頻度やバッチ上限を見直す。Cron設定や変数を変更する場合はWranglerの設定として管理する。コードのロールバックでは既に削除した行は戻らないため、必要ならバックアップから復旧する。
