# パスキーとアカウント同期：要件（実装中）

公開音声はログイン不要とし、お気に入りと再生履歴をD1で端末間同期する。認証はCloudflare Workers上のパスキー、復旧は事前に受信確認したメールアドレス宛の期限付き・一度限りのリンクを用いる。Google・AppleのOAuth連携は利用しない。パスワード、顔、指紋をサービスに保存しない。

1. 本人のデータのみ読み書き・削除でき、管理画面は管理者に限る。
2. 登録とログインで、WebAuthnのチャレンジ・オリジン・RP ID・署名・ユーザー確認を検証する。
3. 復旧アドレスは暗号化して保存し、確認済みのアドレスにだけ復旧リンクを送る。漏えい済みメールアカウントで復旧されるリスクを利用者に伝える。
4. 復旧リンクは推測困難、期限付き、1回限りとし、送信・検証の回数制限とアカウント列挙の対策を設ける。管理者の復旧は別途強化する。
5. 公開前に画面接続、複数端末・復旧・権限の実環境検証と削除・運用手順を整える。
6. 再生開始時、アカウント履歴の読み込みが完了する前に保存済み再生位置を上書きしない。

パスキー登録・ログイン・メール復旧のAPIと画面は実装中。メール送信の実設定と実機・安全性の検証が未完了のため認証は公開しない。
