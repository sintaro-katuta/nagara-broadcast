# アカウント同期：要件（実装中）

お気に入り、再生履歴、再生位置を端末間で同期し、管理者には既存デザインの保存状況を表示する。音声の視聴は従来どおり公開する。メール、名前、パスワードは機能上必要になるまで保管しない。

1. 各利用者は本人のデータのみ読み書き・削除できる。サーバーで検証したセッションから利用者を決める。
2. お気に入りと各音声の最終再生日時・位置をD1に保存する。
3. 管理者だけが登録音声の合計・本数・番組別内訳を確認できる。上限が未設定なら残量と表示しない。
4. 既存デザインを使い、未認証時にも公開音声を再生できる。
5. 個人データや認証トークンをログに記録せず、適切な削除とセッション失効を可能にする。

GoogleとAppleの両方に対応し、Firebase等は使わずCloudflare WorkersとD1でセッションを管理する。異なるプロバイダーは自動統合しない。履歴の保持期間とアカウント復旧方法は未決定。認証とAPIは無効化した状態で組み込み、画面は未接続。
