# 設計

Worker の限定 API は GitHub Actions の `AUTH_RATE_KEY` を使った用途限定 HMAC と2分の時刻制限を検証する。GitHub と Worker の同名キーが一致することが必要。送信可能なのは固定の Resend シミュレーター宛のみで、送信元も固定。認証フラグのどちらかが有効になれば 404 を返す。D1 で24時間あたり3回までに制限し、同じ署名時刻の再試行は同じ Resend 冪等キーを使う。失敗時は詳細やキーを返さず失敗ステータスにする。

既存の Resend アダプターと送信元を使うため、本番 Worker の送信キーとドメイン設定を検証できる。受理は最終配送を意味せず、Resend の履歴で別途確認する。認証用メールの画面・登録・復旧の全体動作は対象外。新規テーブルやマイグレーションは不要。レート枠は既存の `auth_rate_limits` を使用し、利用者向けの送信枠とは別で、Resend 自体の共有枠は消費する。
