# 運用

問い合わせ先を変更するときは、サイトのフッター・ログイン画面の説明・通知メールの3か所を更新し、受信と返信を検証する。受信箱はResendの管理画面から人が対応する。メールの送受信はResendの枠を消費する。

変更のマージ後は、サイトからメールアプリが開くことを確認する。古い送信待ちは既存の文面を維持するため、問い合わせ先は記載されない。ロールバック時は、新文面の送信待ちを古いコードが再送すると、同じ冪等キーで本文が異なり拒否される場合がある。送信済みか不明な通知は保全し、状態を確認してから再送する。本番ログインや通知の有効化、メールの送信、データ移行はこの変更には含まれない。保存期間など未確定の項目を含む正式なプライバシー案内は別途確認する。
