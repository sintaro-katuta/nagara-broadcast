# 運用

マージだけでは DB 更新しない。認証機能を無効にしたまま、バックアップの復元手順を確認し、D1 Write のみの専用トークンを Actions secret `CLOUDFLARE_D1_WRITE_TOKEN` に登録する。既存の `CLOUDFLARE_D1_READ_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` も必要。

変更内容と対象を確認後、`Apply D1 authentication migrations` を main で手動実行し、確認入力に `APPLY AUTH MIGRATIONS` を指定する。ブックマークの取得に失敗すると適用しない。途中で失敗した場合は再実行せず、履歴とログを確認する。ブックマークを用いた復元は実施以降の番組データも巻き戻すため、他の更新を確認してから行う。無料プランの復元可能期間は7日間。実データで復元検証していないため、本番実行前に復元を隔離環境で検証する。

書き込みトークンは使用後に失効し、secret を削除できる。ログイン・通知のフラグ、実メール試験および管理者復旧はこの処理の対象外。
