# 設計

既存の管理者専用 `/api/admin/usage` に、D1のレート制限バケットから取得した登録・通常復旧・管理者復旧の予約数と上限・リセット時刻を追加する。送信側と同じ定数とHMAC鍵からバケットを特定し、個別のアドレスやIPは取得しない。取得不能と0件は区別する。管理画面はResend APIのアカウント使用数、アプリ内の予約数、復旧通知の滞留を別々に表示する。どちらかの枠が80％以上、または要確認の通知があれば画面上に警告する。

アプリ内の予約数は配送数ではない。予約後に送信が失敗した場合も増え、上限を超えた要求は表示上、上限として扱う。Resendの通知・別アプリを含む実際の使用量を代用するものではない。
