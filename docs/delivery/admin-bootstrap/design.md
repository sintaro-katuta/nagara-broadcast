# 設計

本人のログインセッションから、アカウントIDを短く符号化した設定用コードを返す。コードはアカウントIDに戻せる識別子であり、それだけで権限は得られない。操作 API と画面は `ADMIN_BOOTSTRAP_ENABLED=false` が既定。GitHub の運用者が手動ワークフローにコードを渡し、対象 D1 と Worker の設定を検証したうえで D1 を操作する。

管理者が0人、指定アカウントに確認済みメールと有効なセッションがあり、パスキーが2件以上あり、復旧の処理中でないことを1つの INSERT 文で確認して付与する。並行した実行でも2人を初期管理者にしない。対象以外のアカウントを列挙せず、IDやメールはログ出力しない。2件のパスキーが独立した保存先にあることはシステムでは判定できない。
