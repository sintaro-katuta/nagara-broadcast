# 運用

通常のビルド・デプロイ後、トップのフッターから `情報の取り扱い` を開き、問い合わせリンクと表示を確認する。認証を有効にする場合は登録画面からも確認する。運営者名は本人が公開する名前を決めてから追記する。公開前に、保有個人データに関する公表事項、保管・削除の運用、問い合わせ対応を確認する。

Cloudflare D1 のバックアップはプランにより復元可能期間が異なり、Resend もメール・ログを一定期間保持する。期間やプランは変更され得るので、案内では特定の日数を保証しない。データベースを過去に復元すると削除済みのアカウントが復活する可能性があるため、復旧時には削除依頼との照合が必要。ページに問題があればリンクと静的ファイルの変更を戻してデプロイする。DB変更はない。

確認した提供元の情報：[Cloudflare D1 Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/)、[Resend の保持期間](https://resend.com/security/gdpr)、[個人情報保護委員会のガイドライン](https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/)。
