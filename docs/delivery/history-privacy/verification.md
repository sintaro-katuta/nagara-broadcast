# 検証

- 履歴削除後にカーソルが消え、古い世代の書き込みが履歴を復元しないこと、新しい再生は保存できることを確認。
- 別アカウントへの影響がないこと、削除途中の失敗で全変更がロールバックされること、アカウント削除で世代も削除されることを確認。
- API の409とクライアントの再取得、D1 移行の事前確認が予期しない状態を拒否することを自動テスト。
- `npm test`: 117件成功。`npm run build`: 成功。
- 使い捨ての実 D1 で、既存の試験データを保持した移行、削除と同時書き込み、他アカウントへの影響、アカウント削除時の連鎖削除を確認した。[実行結果](https://github.com/sintaro-katuta/nagara-broadcast/actions/runs/45727178844)
- 一時的な Cloudflare Worker と D1 を組み合わせ、HTTP API からの履歴消去と並行する書き込み、他アカウントへの影響を確認し、試験用リソースを削除した。[実行結果](https://github.com/sintaro-katuta/nagara-broadcast/actions/runs/45727561176) 実利用者のデータや実機は使用していない。
