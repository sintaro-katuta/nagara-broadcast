# 公開・運用上の残作業

本番フラグは現状のまま。公開前に以下を完了する。

1. 期限切れ清掃の Cloudflare 定期実行を実環境で検証し、有効化・失敗時の監視と停止方法を確認する。
2. 再生履歴と書き込み順序管理データの削除・保持方針を実装し、遅延リクエストとの競合を検証する。
3. 管理者アカウントの初期設定、独立した複数の認証手段、紛失時の本人確認と復旧を決めて検証する。
4. 本番の Resend 使用量表示には全権限 API キーが必要。権限の広さを確認してから安全に設定する。
5. メール復旧の実機での完了、独立レビュー、利用者向けの保持・削除に関する説明を完了する。

利用者情報の削除・通知などの機能は関連する設定とバックアップを確認してから公開する。使い捨て検証用の Worker と D1 は実行後に削除する。別のログイン検証用ステージングは、検証完了後に個別に片付ける。
