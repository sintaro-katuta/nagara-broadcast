# 運用

`PASSKEY_ADD_ENABLED=false` では追加画面と API は利用できない。新たな DB 移行は不要。公開するには分離環境で追加・通知・複数保存先を実機確認し、パスキーの管理と管理者の復旧を整えてからフラグを判断する。通知は既存の復旧通知キューと再送運用を共有する。問題があれば追加フラグを false に戻す。登録済みのパスキーはフラグの変更では削除されない。

短期の分離プレビュー設定では追加・管理者設定・管理者復旧フラグを有効にするが、プレビュー Worker は定期通知を実行しない。したがって復旧開始メールの送信と、登録後の通知キューからの実配送は別々に検証する。
