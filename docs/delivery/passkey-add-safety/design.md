# 設計

短命で1回限りのチャレンジによって既存パスキーで再認証し、登録画面では別の保存先を案内する。ブラウザトークンとセッションのハッシュで登録試行を識別し、各操作で画面のセッション識別子を照合する。署名カウンター、セッションの有効期限、試行回数を確認する。登録と通知待ちの記録は単一の D1 トランザクションで行い、通知は既存の再試行付きキューを使う。管理画面は復旧とパスキー追加を合わせたセキュリティ通知の件数を表示する。

`PASSKEY_ADD_ENABLED` の既定値は false。追加フラグと既存認証・通知の設定が有効な場合のみ操作できる。パスキーの一覧・個別失効、管理者の復旧手順は対象外であり、公開前に別途必要。
