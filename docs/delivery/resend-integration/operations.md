# 運用と公開条件

Resendの無料アカウントと認証済み送信ドメインを用意する。Cloudflare Workerに送信専用・対象ドメイン限定の `RESEND_API_KEY`、送信元 `AUTH_EMAIL_FROM` を設定する。管理画面の使用量取得が必要な場合のみ別のフルアクセスキー `RESEND_USAGE_API_KEY` を秘密情報として登録する。キーをソースコード、ログ、チャット、ブラウザのレスポンスに含めない。

通知のD1マイグレーションを適用し、送信・通知フラグを有効にする前に、隔離環境で本人確認・メールの受信・復旧・失敗再送・管理者以外の拒否を検証する。無料枠に達したとき登録・復旧メールの送信は失敗する。現在の登録・復旧開始画面はアカウント列挙防止のため共通の回答を返し、メール未達の具体的な理由を利用者に表示しない。管理者は使用量とログで確認する。

`RESEND_USAGE_API_KEY` が未設定・無効なら管理画面は使用量を未取得と表示する。公開前にメールの到達性、バウンス、使用枠の監視と管理者復旧、パスキーの管理・アカウント削除、独立した安全性レビューが必要。機能を停止する場合は `AUTH_ENABLED` と `AUTH_NOTICES_ENABLED` を無効にし、通知待ちは保持する。
