# 設計

Workerは固定の `https://api.resend.com/emails` に送信し、送信専用 `RESEND_API_KEY` を使用する。登録と復旧メールは既存の認証フローに合わせてレスポンスを共通化する。復旧完了通知の再試行では通知IDに基づく冪等キーを付与する。Resendの重複防止は24時間であり、それ以降の重複はあり得る。

アカウント画面には管理者の場合のみ管理情報ボタンを表示する。管理APIではセッション、管理者権限、画面取得時のセッション識別子をサーバー側で検証する。Resend Usage APIは別の `RESEND_USAGE_API_KEY` を使用する。APIがフルアクセス権を必要とするため、送信専用キーとは分けてWorker secretsで保管し、ブラウザへ返さない。レスポンスには日次・月次の使用数、上限、更新時刻のみを含める。

管理画面には復旧完了通知の送信待ちと、恒久的なエラーで要確認となった件数を表示する。宛先やメール本文は含まない。音声容量はD1に登録された音声のサイズの合計であり、R2の全オブジェクトや請求対象の使用量、無料枠の残量ではない。Cloudflare自体の利用枠やResendの配信結果・バウンス件数は未実装。外部APIキーの未設定や取得失敗は未取得と表示する。
